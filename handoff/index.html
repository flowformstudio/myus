Good to know

  • Fonts: the section uses Poppins, which myus.com already loads. No font import inside the block.
  • Images: every image URL starts with https://myus-demo.vercel.app/assets/family/, so the pasted section renders right away. To move them to the MyUS CDN later, upload the assets/family folder and find-and-replace that prefix.
  • Colors and type come from the MyUS tokens already used on the site (navy #10283d, orange #ff981f / #ff7a00, link blue #0c71c9, Poppins).
  • Responsive: breakpoints at 1180, 1024 and 767px match the desktop, tablet and mobile Figma boards.
  • Logged-in state: the pasted version is the signed-out page. The "Add someone to MyUS Family" button variant exists in the demo (Visitor switch) if the site can tell who is signed in.
